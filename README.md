# Gestor de Tareas

Un gestor de tareas sencillo y eficiente diseñado para ayudarte a organizar tus actividades diarias. Este proyecto permite a los usuarios crear, editar, y marcar tareas como completadas, todo desde una interfaz intuitiva y fácil de usar.

## Características principales

- Crear nuevas tareas con títulos y descripciones.
- Editar tareas existentes.
- Marcar tareas como completadas.
- Interfaz simple y minimalista.
