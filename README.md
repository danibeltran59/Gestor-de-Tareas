# Gestor de Tareas

![Logo del Gestor de Tareas](https://via.placeholder.com/600x150.png?text=Gestor+de+Tareas)

Un gestor de tareas sencillo y eficiente diseñado para ayudarte a organizar tus actividades diarias. Este proyecto permite a los usuarios crear, editar y marcar tareas como completadas desde una interfaz intuitiva y fácil de usar.

---

## Características principales

- 📋 Crear nuevas tareas con títulos y descripciones.
- ✏️ Editar tareas existentes.
- ✅ Marcar tareas como completadas.
- 🗑️ Eliminar tareas que ya no son necesarias.
- 💻 Interfaz simple y minimalista.
